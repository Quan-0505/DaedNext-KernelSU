# Changelog

## Manager 0.1.8 — 尚未纳入 Release

- 移除设置页重复的资源工作台，保留底部资源导航及首页资源入口；设置页从外观选项开始。

## v0.1.0-alpha8 — Manager 0.1.7

- 集成 Manager 0.1.2–0.1.7：原生配置、DNS、路由、群组、节点与订阅工作台，四项底部导航，明暗主题与外观选择。
- 首页使用 B 版琉璃鹅核和遵循系统设置的有限时长启停动画；桌面采用 C 版卡通鹅自适应图标及单色主题层。
- 保留 alpha7 核心与服务控制逻辑、数据目录和用户配置。此版只更新管理器、版本标识及文档。
- Release 提供模块 ZIP、独立 Manager APK 两个附件，ZIP 内包含相同签名 APK；无单独校验文件。
- 以下 Manager 分项记录的功能均已纳入 alpha8。

## Manager 0.1.7 — 随 alpha8 发布

- 使用选定的 C 版卡通叼刀鹅桌面图标，拆分透明前景、黄色渐变底和速度线，适配 Android 自适应图标裁切。
- 添加 Android 13 及以上的单色主题图标层，首页 B 版琉璃鹅核及代理操作保持原有行为。
- 沿用原签名覆盖安装，并在一加 13 验证桌面显示、圆形安全区、圆角方形及单色图层。

## Manager 0.1.6 — 随 alpha8 发布

- 首页采用选定的 B 版琉璃鹅核，包含离线浅色／深色透明素材，轨道、粒子和切换效果由原生 Canvas 与有限时长动画实现。
- 代理开启时聚拢点亮，暂停时释放收束并降饱和；默认 1.25 秒，遵循系统动画设置，关闭系统动画时直接更新。
- 实际操作与动画并行，状态文案以模块结果为准；失败后只读核对状态并回退，不自动重发写入。等待确认与动画期间阻止重复点击。
- 首页周期刷新改为原位更新，避免重建球体或重播动画；后台、窗口隐藏及视图移除时停止运动。保持说明区域高度，避免按钮跳动。
- 新增素材来源与生成提示词说明，核心与模块保持 alpha7。

## Manager 0.1.5 — 随 alpha8 发布

- 新增原生资源工作台，六宫格统一配置、DNS、路由、群组、节点与订阅，展示本机实际资源数量；底部第二项改为「资源」。
- 六项统一分类图标、柔和分类色、页面标题、卡片、表单与明暗主题，首页和设置页提供完整资源入口。
- 新增 DNS 方案、上游、查询／响应规则和兜底行为管理；新增响应区块时提供必需的接受兜底。
- 新增路由方案、匹配条件与出口编辑、模板、规则排序／删除和兜底行为管理。六项资源均在原生界面中操作。
- DNS／路由保存前通过本机完整配置预览校验，保留版本检查，保存不自动重载；复杂语法支持原生完整文本编辑。
- 新增原文片段编辑器及纯 Java 回归检查，覆盖引号、注释、多行表达式、规则排序和必需兜底，纳入 CI。

## Manager 0.1.4 — 随 alpha8 发布

- 将配置和群组入口改为独立原生页面，统一卡片、表单、返回导航及明暗主题，不再跳转内嵌面板。
- 配置支持列表、新建／复制、分组参数编辑、选择和删除；保留原有透明代理端口与路由标记，并提供独立的应用操作。
- 群组支持新建、策略编辑、直接节点管理、订阅关联及节点名称筛选、移出成员和删除；改名后需同步路由中的引用。
- 保存配置与策略前检查服务端版本；成员操作按关联增删，避免覆盖其他成员的筛选条件。保存不自动重载。
- 内嵌高级面板仍作为单独的 DNS、路由等高级工具入口。

## Manager 0.1.3 — 随 alpha8 发布

- 首页和设置页新增「配置与群组」卡片，分别直接打开高级面板的配置或群组工作区。
- 节点页「策略组」按钮直接定位群组，不再先进入总览。
- 入口通过根 hash 路由的 `panel` 参数选择工作区，仅接受固定目的地，保留本机 WebView 访问边界。

## Manager 0.1.2 — 随 alpha8 发布

- 新增跟随系统、云雾浅色、星夜深色三种外观选择，保存在 App 本地，覆盖安装保留。
- 浅色采用暖灰白底、近白卡片、墨紫主按钮与雾蓝／灰紫流量数字；原生光核、导航、表单、弹窗和系统栏适配明暗模式。
- 内嵌高级面板同步 App 明暗模式，保留原有强调色。
- 主题切换后保留当前页面，首次状态读取完成后刷新设置开关，避免重建页面时一直显示未读取状态。
- 仅更新 App；核心、模块服务及网络策略保持 alpha7 实现。

## v0.1.0-alpha7 — 2026-10-29

- 新增 DaedNext Manager v0.1.1：原生仪表盘、节点、订阅、网络和设置页面，支持常用模块管理操作。
- 视觉参考 Opal 重设计五个原生页面：暗色卡片、独立绘制的蓝紫光核、统一线条图标、胶囊主按钮和悬浮导航；首页显示实际流量，时间转换为手机本地格式。
- 在 App 内嵌现有高级面板，管理策略组、节点选择、DNS 与路由；不暴露 Root JavaScript 桥，仅允许本机服务地址。
- 新增 Root 本地 socket 的 `manager-session` 会话签发，沿用现有用户，令牌有效期 10 分钟；HTTP 不开放该操作，不返回密码或签名密钥。
- 保留代理启用意图及 Wi-Fi 黑白名单语义；App 通过模块接口修改配置，不直接写数据库。
- ZIP 内附 `manager/DaedNext-Manager.apk`，需手动安装与 Root 授权。Release 继续只发布 ZIP。
- 增加无需 Gradle 的原生构建脚本和无签名密钥的 CI 编译检查，覆盖更新沿用本地签名身份。
- 核心更新为 `3.1.0-android-ksu.6`。

## v0.1.0-alpha6 — 2026-10-27

- 新增 Wi-Fi 黑名单、白名单与独立的非 Wi-Fi 网络代理开关；新安装默认关闭且名单为空。
- KernelSU WebUI 支持分别保存黑白名单、添加当前 Wi-Fi、展示当前网络及策略直连状态；通过 Base64 传递 SSID，避免 Shell 拼接。
- 策略直连保留管理面板与用户配置，释放本模块的数据面；离开直连网络后按用户原启用意图恢复，手动停止不会被网络变化覆盖。
- 连续两次网络观察一致后应用策略，按实际出口而非仅凭已连接 SSID 判断；未知 SSID 或路由空档不新增意外直连。
- Wi-Fi 设置持久化并纳入一致性备份；已启用的 Google 联网兼容在用户仍启用内核的策略直连期间继续维护。
- 核心更新为 `3.1.0-android-ksu.5`，新增策略决策、运行时生命周期及 WebUI 回归测试。

## v0.1.0-alpha5 — 2026-10-27

- 修复网络接口变化但配置未变化时，恢复操作误走状态更新而未重新绑定数据面的问题。
- 网络恢复保留已提交的路由及 geodata 版本，启动恢复避开正在进行的接口重建，减少重复重建与连接中断。
- Android 的启动与运行期探测均使用实际策略路由，同时监测 IPv4、IPv6，忽略占位接口。
- 切换网络后丢弃旧出口的节点健康缓存，立即在新出口重新探测；新安装默认检查间隔调整为 50 秒，已有用户配置保留。
- 核心版本更新为 `3.1.0-android-ksu.4`；保留账户、订阅、节点和 Google 联网兼容设置。

## v0.1.0-alpha4 — 2026-10-27

- 增加默认关闭的 Google 服务联网兼容开关；仅在代理内核运行时维护商店与 Google 服务权限，停止时还原，框架 ABI 严格校验。
- 修复启动后立即停止时 readiness 阻塞造成的超时。
- 完成标准安装、重启、5G 商店首页、网络切换及策略还原实测。

## v0.1.0-alpha3

- Android 控制标记改为 0x01000000；蜂窝 QoS 改写包标记时从原始 socket 识别自身流量，避免 DNS 自循环。
- 网络命名空间重建时使用空闲编号，解决旧命名空间仍被引用的冲突。

## v0.1.0-alpha2

- 订阅、geodata 辅助进程与 Android 控制层 socket 使用一致的 SO_MARK。
- 持久化数据和账户保留、系统 TLS 信任库、开机服务及标准 KernelSU 安装。
