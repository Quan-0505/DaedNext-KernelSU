# Manager 0.1.4 界面规范

## 原生配置与群组

首页、设置页及节点页进入原生配置／群组页面。保留五项底部导航，二级页面使用独立标题和右上返回按钮；群组成员页先返回群组列表，再返回入口页。无需加载 WebView。

配置列表展示已选状态、检查间隔、拨号模式与日志级别。编辑表单按连接与探测、拨号与日志、接口与兼容分组，使用文本输入、下拉选择与开关。透明代理端口和路由标记沿用原值。保存与应用分开，提交失败保留表单。

群组卡片展示策略中文名称、直接节点／订阅／候选数量。运行时没有真实出口数据时，探测结果明确标作「最近探测优选」。成员按节点与订阅分别管理，正则筛选与匹配节点放在订阅成员表单中。危险操作使用主题对应的红色与确认框。

## 外观模式

设置 → 外观提供「跟随系统」「浅色 · 云雾」「深色 · 星夜」。首次使用跟随系统，手动选择保存在 App 私有偏好中，覆盖安装保留。切换不调用模块写入接口，不改变代理启用意图、名单或订阅。原生窗口、系统栏、表单、弹窗和内嵌高级面板使用同一明暗模式，高级面板保留原有强调色。

云雾主题采用偏暖的灰白背景与近白卡片，使用淡紫控件底色和墨紫主按钮区分操作层级。主文字使用深蓝灰；下载与上传分别使用深雾蓝和灰紫，危险操作使用深玫红，避免浅底上的低对比度粉色。光核保留蓝紫渐变，以轻薄光晕和灰紫轨道融入浅底；不增加持续动画。

## 视觉层级

- 首页：品牌与页面标题 → 连接光核 → 当前连接状态 → 代理主开关 → 当前网络 → 真实上传／下载速度。
- 节点、订阅、网络、设置：统一深色卡片、标题间距、胶囊按钮和底部导航。危险操作使用柔红色文字，保留二次确认。
- 内嵌高级面板随 App 的明暗模式切换，保留其既有主题配色与配置能力。

## 图形与状态

`ConnectionArtView` 用原生 Canvas、渐变和曲线路径绘制抽象光核。启用意图开启时呈现蓝紫／青色，暂停时降低饱和度；它表达应用状态，不是网络质量评分或加密保证。图形没有持续动画循环，不需要外部图片或网络资源。页面切换只使用短暂淡入。

`NavIconView` 绘制统一线宽的五个导航图标，避免不同 Android 字体把 Unicode 图标渲染成不同风格。

## 数据与交互

- 首页速度来自模块实际运行概况；没有数据时显示 `—`。直连期间说明 Wi-Fi 上游流量不计入手机代理统计，不填充演示数据。
- 仅前台刷新状态和概况，离开 App 后停止轮询。
- 名单仍分别保存，启停仍使用原有模块接口；视觉调整不改变用户启用意图和网络策略。
- 并列按钮顶部对齐，防止非对称 margin 与垂直居中造成底边裁切。
- 表单使用对应主题的填充色，提交失败保留输入。时间戳转换为手机本地时间，不直接展示 ISO 格式。
- 日志只在维护入口显示；首页不展示内部进程或运行时结构。
