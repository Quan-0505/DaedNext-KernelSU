# Manager 0.1.1 界面规范

视觉方向参考 [Opal](https://opalapp.com/) 的暗色空间、发光视觉重心和清晰的主操作层级。界面、图标及连接光核均独立实现，未打包 Opal 的图片、商标或字体。

## 视觉层级

- 首页：品牌与页面标题 → 连接光核 → 当前连接状态 → 代理主开关 → 当前网络 → 真实上传／下载速度。
- 节点、订阅、网络、设置：统一深色卡片、标题间距、胶囊按钮和底部导航。危险操作使用柔红色文字，保留二次确认。
- 内嵌高级面板进入暗色模式，保留其既有主题配色与配置能力。

| Token | 值 |
| --- | --- |
| 页面底色 | `#090A10` |
| 卡片 | `#171820` |

| 字体 | Android 系统 sans-serif，标题 medium |

## 图形与状态

`ConnectionArtView` 用原生 Canvas、渐变和曲线路径绘制抽象光核。启用意图开启时呈现蓝紫／青色，暂停时降低饱和度；它表达应用状态，不是网络质量评分或加密保证。图形没有持续动画循环，不需要外部图片或网络资源。页面切换只使用短暂淡入。

`NavIconView` 绘制统一线宽的五个导航图标，避免不同 Android 字体把 Unicode 图标渲染成不同风格。

## 数据与交互

- 首页速度来自模块实际运行概况；没有数据时显示 `—`。直连期间说明 Wi-Fi 上游流量不计入手机代理统计，不填充演示数据。
- 仅前台刷新状态和概况，离开 App 后停止轮询。
- 名单仍分别保存，启停仍使用原有模块接口；视觉调整不改变用户启用意图和网络策略。
- 并列按钮顶部对齐，防止非对称 margin 与垂直居中造成底边裁切。
- 表单使用暗色填充，提交失败保留输入。时间戳转换为手机本地时间，不直接展示 ISO 格式。
- 日志只在维护入口显示；首页不展示内部进程或运行时结构。
