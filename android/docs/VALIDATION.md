# Android 实测记录

## alpha5 — 2026-10-27

设备及系统沿用下方 alpha4 环境。本轮 Wi-Fi 上游本身提供代理，因此 Wi-Fi HTTPS 成功不单独证明手机已完成代理链路；无上游代理 Wi-Fi 待补测，5G 为独立蜂窝验证。核心 `3.1.0-android-ksu.4`，节点健康检查间隔 50 秒。

| 项目 | 结果 |
| --- | --- |
| Rust 回归 | 恢复相关 45 项、接口监测 39 项全部通过；覆盖相同配置强制重绑、保留产品版本、启动恢复避让、旧出口健康缓存失效及双协议栈路由探测。 |
| 网络切换 | 连续 3 轮 Wi-Fi ↔ 5G 均自动恢复；6 次切换中核心进程 PID 不变，每次只重建一次，未出现启动恢复重复介入。 |
| 真实联网检查 | 每轮严格 TLS 检查 Google 204、YouTube 200、Telegram Web 200。Wi-Fi→5G 本次 3 个样本从切换到接口和可用节点就绪约 5.6～7.4 秒；Wi-Fi 方向约 12.4～13.8 秒。 |
| 配置不变的接口变化 | 调整并还原 Wi-Fi MTU，数据面自动重新绑定；测试后恢复原 MTU。 |
| 正式安装及数据 | KernelSU 安装成功，活动目录及重启待应用目录的 127 个运行文件校验通过。包含 WAL 的 SQLite 备份对比确认账户、订阅、节点、策略组及绑定数据未改变；按用户要求将原检查间隔改为 50 秒。 |
| 附加检查 | 国内直连 HTTPS 200；携带 Android INET 组的 Play UID 请求返回 302、Google 服务 UID 返回 204，TLS 校验均为 0。独立 IPv6 Google HTTPS 请求超时，本轮未通过 IPv6 端到端验证。 |
| 稳定性短测 | 最后一轮切换后连续观察，重载计数保持不变。用户反馈实际应用正常有网。 |

alpha5 此轮未重新执行冷启动；下方 alpha4 冷启动结论不代表 alpha5 已完成相同验证。切换中连接可能中断，恢复还受节点探测及网络条件影响；上述时间为本设备本次样本，不是所有网络的恢复时限。原始运行日志及数据库只保留在私有验证目录。
